# ES6+


`ES6` 是 [ECMA](https://www.ecma-international.org/publications-and-standards/standards/ecma-262/) 为 `JavaScript` 制定的第 6 个标准版本。
`ES6` 既是一个历史名词也是一个泛指，含义是 `5.1` 版本以后的 JavaScript 下一代标准。
